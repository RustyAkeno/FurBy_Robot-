# FurBy_Robot-
Бот в ТГ для принятия анкет от пользователей для вступления в чат (не только)

Можно быстро делать разные версии бота:

• для фурри-чата

• для закрытого сообщества

• для игрового клана

• для тематического канала

• для любого отбора по анкете

▎Меняется без переписывания кода

Человеку достаточно поменять:

• PROJECT_NAME

• тексты вопросов

• тексты приветствия

• ID чатов

• текст кнопок
